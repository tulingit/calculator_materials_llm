# TN Agent — чат-ассистент для расчёта строительных материалов

Чат-бот на сайте Центр СМ. Клиент пишет в чат, что хочет посчитать.
Агент ведёт диалог, собирает параметры, и в фоне (через Playwright)
считает материалы на калькуляторе ТЕХНОНИКОЛЬ. Клиент видит результат
в нашем интерфейсе и не уходит на сторонние сайты.

---

## Что уже работает

- Чат-виджет на сайте (плавающая кнопка + модальное окно).
- LLM-агент на базе OpenAI-совместимого API (по умолчанию gpt-4o-mini).
- Tool-calling: агент вызывает наш расчёт, а не считает сам.
- Playwright-адаптер для калькулятора гибкой черепицы SHINGLAS
  на tn.ru (сбор данных → расчёт → чтение результата).
- Память диалога в сессии (in-memory).
- Подложка — сайт Центр СМ в iframe под нашим виджетом.

## Что пока НЕ работает

- Очередь и постоянное хранилище сессий (сейчас всё в памяти).
- Дополнительные параметры калькулятора (кирпичная труба, мансардное окно,
  канализационный выход, точечные аэраторы).
- Другие калькуляторы ТЕХНОНИКОЛЬ (водосток, пена и т.д.).
- Стриминг ответа LLM (ответ приходит целиком, а не по частям).
- Прод-деплой.

## Быстрый старт

### 1. Клонировать репозиторий

```bash
git clone <url-репозитория>
cd tn-agent
2. Создать виртуальное окружение
bash
python -m venv .venv

# Windows
.venv\Scripts\activate

# macOS / Linux
source .venv/bin/activate
Важно: проект рассчитан на Python 3.12. На Python 3.14 часть
библиотек (playwright, pydantic-core, greenlet) пока не имеет
готовых wheels и не собирается.

3. Установить зависимости
bash
pip install -r requirements.txt
playwright install chromium
4. Заполнить .env
Скопируй .env.example в .env:

bash
# Windows
copy .env.example .env

# macOS / Linux
cp .env.example .env
Открой .env и вставь свой ключ LLM:

env
OPENAI_API_KEY=sk-...
OPENAI_BASE_URL=https://api.openai.com/v1
OPENAI_MODEL=gpt-4o-mini
HOST=0.0.0.0
PORT=8000
HEADLESS=true
TN_TIMEOUT_SEC=90
Если используешь другого провайдера (OpenRouter, YandexGPT и т.д.) —
поменяй OPENAI_BASE_URL и OPENAI_MODEL соответственно.

5. Запустить сервер
bash
python run.py
Открой в браузере: http://localhost:8000

Ты увидишь сайт Центр СМ в подложке, а слева внизу — кнопку чата
с иконкой калькулятора.

Как пользоваться
Кликни по кнопке-калькулятору в левом нижнем углу.

Напиши, что нужно посчитать, например: «посчитай гибкую черепицу».

Агент задаст уточняющие вопросы: тип крыши, коллекция, цвет,
площадь, угол ската, длина конька и карнизов.

После сбора данных агент запустит Playwright-адаптер, который
сходит на tn.ru и вернёт результат.

Результат появится в чате.

Переменные окружения
Переменная Назначение Значение по умолчанию
OPENAI_API_KEY Ключ LLM-провайдера —
OPENAI_BASE_URL Базовый URL API https://api.openai.com/v1
OPENAI_MODEL Модель gpt-4o-mini
HOST Хост Uvicorn 0.0.0.0
PORT Порт Uvicorn 8000
HEADLESS Playwright без окна true
TN_TIMEOUT_SEC Таймаут на один расчёт 90
API
Метод Путь Что делает
GET / HTML-виджет
POST /api/session Создаёт новую сессию диалога
POST /api/chat Отправляет сообщение клиента, получает ответ агента
POST /api/reset Очищает историю сессии
Пример запроса /api/chat:

json
{
  "session_id": "abc123",
  "message": "посчитай гибкую черепицу"
}
Как это работает внутри
text
Клиент в чате
    │
    ▼
FastAPI /api/chat
    │
    ▼
LLM-агент (tool-calling)
    │   ├─ задаёт уточняющие вопросы
    │   └─ когда данных достаточно — вызывает tool
    │
    ▼
run_tn_shinglas(params)
    │
    ▼
Playwright: открывает tn.ru, кликает, читает результат
    │
    ▼
Ответ возвращается агенту → клиенту
Правило номер один: LLM никогда не считает материалы сама.
Все числа приходят только из tools. Это гарантирует точность.

Отладка
Playwright-адаптер падает
Запусти вручную:

bash
python test_adapter.py
Перед этим поставь в .env:

env
HEADLESS=false
Откроется окно браузера — своими глазами увидишь, где именно
останавливается сценарий. Селекторы можно поправить
в app/adapters/tn_shinglas.py.

Агент отвечает странно
Проверь системный промпт в app/agent.py. Обычно проблема там
или в описании tools в app/tools.py.

Медленные ответы LLM
Проверь провайдера в .env (OPENAI_BASE_URL).

Можно поменять модель на более быструю.

Смотри раздел «Что можно улучшить».

Что можно улучшить
Стриминг ответа LLM. Клиент видит текст сразу, а не ждёт целиком.
Субъективно ускоряет ответ в 5–10 раз.

Быстрый парсер простых ответов. «Галька», «30», «100» — можно
распарсить регэкспом без LLM. Это экономит 3–10 секунд на каждом шаге.

Redis для сессий. Сейчас истории диалогов в памяти: рестарт сервера
их удаляет.

Дополнительные параметры SHINGLAS. Трубы, окна, канализация,
точечные аэраторы — увеличивают точность расчёта.

Другие калькуляторы ТЕХНОНИКОЛЬ. Водосток, монтажная пена,
теплоизоляция и т.д. — по аналогии с SHINGLAS.

Очередь задач и пул воркеров. Если одновременно много клиентов.

Кэш результатов по хэшу входных данных на 10–30 минут.

Прод-деплой с мониторингом (Sentry, Prometheus, Grafana).
